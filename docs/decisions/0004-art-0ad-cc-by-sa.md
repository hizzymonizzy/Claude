# 0004 Art adapted from 0 A.D., top-down

**Context.** We tried an isometric diorama; the player rejected it because it didn't suit mapping real roads. A top-down,
Orna-style map was preferred.

**Decision.** Textures and portraits are adapted from 0 A.D. (Wildfire Games, CC BY-SA 3.0), fetched from the
official repository into quarantine and re-encoded by `tools/asset_intake.py`. Files are prefixed `oad_*` and
credited in Settings and `CREDITS.md`. Everything else is original (`tools/gen_sprites.py`).

**Consequences.** Adapted art is share-alike. Kenney and other sources would need an environment and intake
review first. The player declined adding kenney.nl.
